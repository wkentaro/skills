# Triage labels

The skills use five standard triage roles. This file maps each role to the label string in this repository's issue tracker.

| Standard role       | Tracker label       | Meaning                                  |
| ------------------- | ------------------- | ---------------------------------------- |
| `needs-triage`      | `needs-triage`      | A maintainer must evaluate the issue     |
| `needs-info`        | `needs-info`        | Waiting for more information             |
| `ready-for-agent`   | `ready-for-agent`   | Fully specified and ready for an agent   |
| `ready-for-human`   | `ready-for-human`   | Requires human implementation            |
| `wontfix`           | `wontfix`           | No action will occur                     |

When a skill names a standard role, use the tracker label from this table.

Edit the right column if the repository changes its label names.
